# ResQ-Route-Web-App

> Real-Time Emergency Vehicle Corridor Early Warning System

ResQ-Route links emergency vehicle telemetry directly to civilian driver dashboards—calculating exact route proximity and warning drivers kilometers in advance to clear a safe corridor.

## Features
- **Instant Proximity Countdown**: Real-time HUD showing distance countdown to approaching ambulances.
- **Directional Geo-Fencing**: Distinguishes whether the emergency vehicle is behind you on the same road or on an opposing lane.
- **Zero Municipal Infrastructure**: Works directly on Android devices and modern web browsers.
- **Privacy First**: Civilian locations are processed on-device; no tracking or telemetry logging.

## Technologies Used
- HTML5 & Modern Vanilla CSS (Fluid, responsive, modern dark theme)
- Vanilla JavaScript (High-performance GPS route simulation, HUD countdown)
- Google Fonts: Outfit, Plus Jakarta Sans, Space Grotesk
- Vercel Deployment Ready
